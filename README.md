# Emotion Detector

## Project Description

Emotion Detector is an AI-based web application that detects emotions from user-provided text using the IBM Watson NLP library.

The application identifies the following emotions:

- Anger
- Disgust
- Fear
- Joy
- Sadness

It also determines the dominant emotion from the detected emotion scores.

## Technologies Used

- Python
- IBM Watson NLP
- Flask
- Unit Testing
- Static Code Analysis
